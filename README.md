# COMP 310 Assignment 1 - Building an OS Shell
## Rachel Ruddy and Ash Nandi

### Project compilation
To compile the project:
1. cd to ./project/src
2. run: make clean; make mysh;

### Running the shell
To run the shell after project compilation, run: ./mysh

### Using our test scripts to run assignment test cases
To run our custom test script that runs all 10 test cases
1. Ensure project is compiled
2. cd to ./test-cases
3. run: ./run_tests.sh
